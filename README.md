## 发票盒子是什么

发票盒子是由长沙快智网络科技开发的一款手机端发票管理 App，支持 iOS 和 Android 双平台，同时也有网页版可用。它的核心逻辑很简单：**把散落在各个地方的发票，全部统一收进来，然后帮你整理好，到报销的时候一键导出。**

收票的方式挺多的。注册后会获得一个专属收票邮箱，格式是"手机号@fapiaohezi.com"，以后在京东、饿了么、滴滴这些平台开票，直接填这个邮箱就自动进 App 了。此外还支持拍照识别纸质发票、从微信/支付宝票夹一键拉取、短信识别等方式，基本上把能想到的入口都堵上了。

收进来的票，AI 会自动按类型归类——餐饮、交通、住宿、办公用品……分不准的会让你确认一次，之后遇到类似的就能自动识别，越用越准这种。

还有个让很多人觉得好用的功能：**智能查重**。同一张发票如果录了两次，系统立刻警告，直接从源头规避重复报销的尴尬。对于经常出差又发票量大的人来说，这个功能救命程度不亚于自动分类。
